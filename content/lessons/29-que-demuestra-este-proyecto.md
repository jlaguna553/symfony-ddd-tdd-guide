Un CRUD sencillo puede demostrar muy poco:

```flow
Controller
ORM
Database
```

Este proyecto demuestra bastante más:

- DDD
- TDD
- Dependency Inversion
- CQRS
- Repository Pattern
- Doctrine
- MySQL
- Integration Testing
- Functional Testing
- Error Mapping
- Database Integrity
- CI
- Static Analysis
- Architecture Enforcement

Eso ya es material para discutir arquitectura de software con cualquier interlocutor técnico, no solo para pasar una demo.
